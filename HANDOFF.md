# Перенос из прошлой сессии

## Вопрос

> А к iRobot Braava Jet m6 можно по Wi-Fi подключиться?

## Ответ

Да, у **Braava Jet m6** есть **локальный Wi-Fi-интерфейс** — это совсем другой
механизм, чем serial-порт у старой Roomba 550.

Как это работает:

- Робот подключается к Wi-Fi **2.4 ГГц** и общается **локально по MQTT поверх
  TLS (порт 8883)**.
- В сети он находится по **UDP-бродкасту (порт 5678)**.
- Готовые реализации: `roombapy` (Python), `dorita980` (Node.js), интеграция
  `irobot` в Home Assistant.

Что можно через это:

- запуск/пауза/стоп/док, статус, батарея, ход уборки, ошибки, часть телеметрии;
- всё по локальной сети, без облака (после первичной привязки).

Что нужно и что нельзя:

- Нужны **BLID и локальный пароль** робота. Их обычно берут **один раз из
  облака iRobot** по аккаунту (можно через VPN), дальше можно локально.
- **Карты нет** — она только в облаке, локально робот её не отдаёт (как и у
  новых Roomba).
- Робот всё равно пытается достучаться до облака; если не может — может виснуть
  на загрузке карты.

Итог: **к m6 по Wi-Fi подключиться и управлять — можно** (локальный
MQTT-протокол), но это «управление без карты», и для пароля разово понадобится
облако. Serial-порта, как у 550, у него нет — только Wi-Fi/облако.
