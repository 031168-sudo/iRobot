# AGENTS.md — проект «МойРобот» (BraavaLocal)

## Что это

Android-приложение для **локального управления iRobot Braava Jet m6 по Wi-Fi**,
без облака: MQTT 3.1.1 поверх TLS, порт **8883**; обнаружение — UDP **5678**.
Пакет `com.braava.local`, Kotlin + Jetpack Compose.

- **Репозиторий:** https://github.com/031168-sudo/iRobot
- **Текущая версия:** 2.19 (`versionCode 30`), ветка `master`.
- **Актуальное состояние и передача:** `HANDOFF.md`.
- **Детали протокола и телеметрии:** `SESSION.md`.

## Устройства и каналы управления

### iRobot Roomba 550 (серия 500, старая)
- Управление: **serial-порт ROI/OI**, 7-пин **mini-DIN** (похож на S-Video),
  на верхней части робота под заглушкой.
- Уровни **TTL 0–5 В**, нужен USB-TTL адаптер или готовый кабель Roomba→USB.
- Скорость **57600, 8N1** (у старых моделей встречается 19200/115200).
- Распиновка: 1,2 Vpwr; 3 RXD; 4 TXD; 5 DD (Device Detect — будит); 6,7 GND.
- Команды OI: `128` Start, `131` Safe, `132` Full, `135` Clean, `134` Spot,
  `136` Max, `143` Seek Dock / `156` Dock, `137` Drive, `138` Motors, `139` LEDs,
  `140/141` Song/Play, `142` Sensors, `148/149` Stream/Query list, `152` Schedule,
  `153` Set day/time, `129` Baud, `133` Power.
- Беспроводное: **Rootooth** (Bluetooth) или ESP32/ESP8266 в тот же порт.
- **Карты нет** — 500-я серия не строит карту.
- **Прошивка**: только через фирменный **OSMO** (образ залит на заводе; самому
  залить нельзя, образов iRobot не публикует). В порту одновременно только одно
  устройство — OSMO и Bluetooth придётся переставлять.

### iRobot Braava Jet m6 (новая)
- Управление: **Wi-Fi 2.4 ГГц**, локальный **MQTT поверх TLS, порт 8883**;
  обнаружение по **UDP 5678**.
- Библиотеки: `roombapy` (Python), `dorita980` (Node.js), HA-интеграция `irobot`.
- Нужны **BLID + локальный пароль** (берутся из облака iRobot один раз).
- **Карты нет** локально — только в облаке.
- Serial-порта нет.

### Xiaomi Mi Robot Vacuum 1S (`roborock.vacuum.m1s`)
- Локальное управление: **miIO**, UDP **54321**, AES-128-CBC, нужен **токен**
  (32 hex). Токен выдаётся при привязке к Mi-аккаунту (CN) и не меняется.
- В приложении: вкладка **«Xiaomi»** — вход в Mi-аккаунт, выбор робота, IP;
  токен сохраняется локально.
- Команды: `app_start`, `app_stop`, `app_pause`, `app_charge`, `find_me`,
  `get_status`, `get_room_mapping`, **`app_segment_clean`** (уборка комнат).
  `app_zoned_clean` (зоны по координатам) у `m1s` **нет**.
- **Карта — только в облаке**: `get_map_v1` возвращает указатель, файл
  скачивается с `api.io.mi.com`. Локально карты нет.
- На базе робот может спать и не отвечать на miIO, пока его не разбудят
  (запуск уборки/кнопка); во время уборки отвечает нормально.

## Ограничения, о которых помнить

- Облако iRobot для РФ недоступно без VPN; робот виснет на загрузке карты,
  когда не может достучаться до сервера.
- Локально можно управление, но **без карты**.
- Полный доступ к карте — только через облако (VPN на уровне сети робота,
  например GL.iNet за 4G-роутером).
- m6 принимает **одно локальное MQTT-соединение**: второй клиент (телефон,
  Home Assistant, `roombapy`) может мешать подключению.
- Команды нужно отправлять с **QoS 0**; на QoS 1 брокер не подтверждает.
- `train` создаёт версии карты, но **не промоутит** `active_pmapv_id`; это
  делает облако/нативное приложение.

## Правило

**Коммит/пуш — только по явной команде пользователя.**

**«коммить/закоммить»** означает:
1. `git add -A` и коммит всех изменений;
2. `git push` в GitHub — дальше APK собирает GitHub Actions.

Локальная сборка перед коммитом — по возможности, если в окружении есть
Android SDK. На сервере без SDK она не требуется: каноническая сборка идёт в CI.
Отдельной публикации APK на этом сервере больше нет.

## Сборка и CI

- **Каноническая сборка:** GitHub Actions `.github/workflows/android.yml`
  на push в `master` и по `workflow_dispatch`.
- **Релиз с постоянной ссылкой:** `.github/workflows/release.yml` на тег `v*`
  (или ручной запуск) собирает тот же debug APK и прикрепляет его к GitHub
  Release под двумя именами:
  - **всегда последняя версия** —
    `https://github.com/031168-sudo/iRobot/releases/latest/download/MyRobot.apk`
  - конкретная версия —
    `https://github.com/031168-sudo/iRobot/releases/download/v2.8/MyRobot-2.8.apk`
  После зелёной сборки новой версии ставить тег `vX.Y` и пушить его — это и
  есть «прямая ссылка на APK» для пользователя (без страницы Actions).
- CI ставит JDK 17, использует предустановленный Android SDK на `ubuntu-latest`,
  выполняет `./gradlew :app:assembleDebug` и выкладывает артефакт
  **`braavalocal-debug-apk`**.
- Локально (опционально, при наличии SDK):
  `./gradlew :app:assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`.
- Подпись: общий debug-ключ **в репозитории** `keystore/debug.keystore`
  (`alias=androiddebugkey`, пароли `android`) — чтобы CI и локальные сборки
  совпадали и обновления ставились поверх старой версии. Ключ намеренно
  публичный (приложение некоммерческое).
- В git **не хранятся**: `local.properties`, `.gradle/`, `app/build/`,
  `*.apk`, `*.aab` (см. `.gitignore`).
